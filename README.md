# 🏋️ Sports App

A modern Flutter application that provides a clean and responsive interface for browsing sports products. The project is built using Flutter and follows a feature-based folder structure inspired by Clean Architecture to ensure scalability, maintainability, and code reusability.

---

## ✨ Features

- Home Screen
- Shop Screen
- Profile Screen
- Settings Screen
- Search Bar
- Bottom Navigation Bar
- Reusable Custom Widgets
- Responsive UI

---

## 🏛️ Architecture

The project follows a **Feature-Based Clean Architecture**, where the code is organized into reusable and scalable layers.

### Core

Contains shared resources used across the application.

- API
- Constants
- Reusable Widgets
- Assets

### Features

Each feature is organized independently.

- Home
- Shop
- Profile
- Settings

---

## 📂 Project Structure

```text
lib
│
├── core
│   ├── api
│   ├── assets
│   ├── constants
│   └── widgets
│
├── features
│   ├── home
│   ├── shop
│   ├── profile
│   └── settings
│
└── main.dart
```

## 🚀 Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
